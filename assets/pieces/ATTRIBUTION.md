# Piece models

"Staunton Chess Pieces" by DrSteele, https://www.thingiverse.com/thing:5470356,
licensed under Creative Commons Attribution (CC BY): https://creativecommons.org/licenses/by/4.0/

Changes made here: one `*_full.stl` per piece type, converted to metres, the base moved to the origin,
the knight turned to face +x, reduced to 12,000 triangles, saved as OBJ with smooth normals. 
The original STL files are not included in this repository.
